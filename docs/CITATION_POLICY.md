# Citation policy

- Record `original_publication_url` pointing to the earliest reliable paper, publisher record, DOI or repository page.
- Record `source_url` for acquisition and `license.evidence_url` for terms.
- `bibliographic_reference` is human-readable; `citation_keys` refer to `CITATIONS.bib`.
- For items with no verified paper/author, use an honest `@misc` entry, and mark verification work needed.
- If a dataset is a subset or transformed copy of an upstream set, cite both its curation work and the underlying gold source; don't double-count it.
- For research experiments, cite the actual release version used, not just the repository catalogue.
