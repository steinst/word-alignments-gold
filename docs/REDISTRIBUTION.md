# Redistribution policy

This repository's goal is discoverability, not license laundering. The initial ZIP contains **zero third-party corpus files**.

A dataset's rights may have multiple layers:

1. **Alignment annotations**: copyright/license for the links and annotation guidelines.
2. **Underlying sentences/translations**: copyright or license for the bilingual texts.
3. **Database rights**: possible additional rights depending on jurisdiction.
4. **Dataset access contract**: registration, LDC agreement, or institutional license.
5. **Derived normalized files**: adaptation rights; e.g. CC BY-NC-ND does not authorize sharing derivative remixes.

## Decision rules

- **CC BY / CC BY-SA**: share with attribution, notices, license and changes marked, and share-alike where required; confirm full corpus component rights first.
- **CC BY-NC-SA**: noncommercial sharing can be permitted with conditions. This repository defaults to **metadata/link-only** to avoid ambiguity about scope, source text, and future uses; noncommercial is not the same as merely 'publicly hosted'.
- **CC BY-NC-ND**: unmodified, noncommercial copies may be shareable with proper notice; derived tokenization or normalization may not be shared. Project policy: link-only absent permission.
- **Partial/component license**: record/open-license components separately; do not copy other components.
- **No explicit license**: link only and ask rights holder for authorization.
- **Controlled-access/LDC**: list catalogue and acquisition page; never mirror.

## Before adding any original files

- [ ] Record source URL, publisher, version and download date.
- [ ] Preserve original LICENSE/README/NOTICE files.
- [ ] Confirm rights for both alignments **and** bilingual sentences/translations.
- [ ] Check whether the source explicitly requires contacting publisher or registration.
- [ ] Record license evidence URL and reviewer/date.
- [ ] Record SHA-256 of original archive and file.
- [ ] Add attribution and any changes/derivative provenance.
- [ ] Confirm that modified representations comply with ND/SA restrictions.
- [ ] Exclude all restricted, unclear, or contract-controlled data.

This is project curation guidance, not legal advice. Review authoritative terms before distribution.
